## LanShare 1.5.0

局域网文件互传工具，Windows x64 免安装版。

### 这个版本有什么

- **原生桌面窗口**：淡紫主题、圆角按钮、可爱气泡提示
- **自动发现设备**：同一个局域网打开即见，也可手动填 IP
- **文件互传**：浏览对方磁盘、上传、下载、B 到 C 直接传
- **断点续传**：大文件中断后重发接着传
- **小文件加速**：连接复用 + 批量打包，几百个零散文件也不掉速
- **挂载磁盘**：把对方磁盘挂成「我的电脑」里的网络驱动器
- **开机静默自启** + **系统托盘**
- **手机网页版**：浏览器打开 `http://电脑IP:8765/` 即可

### 怎么用

1. 下载下面的 `LanShare-1.5.0-windows-x64.rar` 并解压
2. 双击 `LanShare.exe` 就能用，**无需安装 Python 或任何依赖**
3. 其它电脑同样来一份，左边就会自动出现对方

> 连不上时，双击 `放行防火墙.bat`（需要管理员权限）放行端口。
